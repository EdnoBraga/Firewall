# Scripts de Firewall

Este repositório contém scripts relacionados à configuração e gerenciamento de regras de firewall.

## Características

- Scripts para limpar e configurar regras de firewall
- Script para automação de tarefas relacionadas ao firewall

## Como usar

Execute os scripts conforme a necessidade com o seu interpretador de comandos preferido.
